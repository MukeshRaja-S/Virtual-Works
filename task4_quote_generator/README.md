# Task 4 — Quote Generator with History

This mini-application is implemented in the shared root server.

- Frontend section: `static/index.html`
- Frontend behavior: `static/script.js`
- Backend routes: `main.py` (`GET /api/quotes/random`, `GET /api/quotes/history`)
- Database model: `models.py` (`quote_history` table)
- External source: `https://dummyjson.com/quotes/random`
